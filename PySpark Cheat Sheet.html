Session Setup

from pyspark.sql import SparkSession
from pyspark.sql import functions as F
from pyspark.sql.types import *

spark = SparkSession.builder \
    .appName("MyApp") \
    .config("spark.sql.shuffle.partitions", "8") \
    .getOrCreate()

# Reuse existing session (safe to call anywhere)
spark = SparkSession.getActiveSession()

# Stop session when done
spark.stop()

Read Data

# CSV
df = spark.read.csv("path/file.csv", header=True,
                         inferSchema=True)

# JSON (one object per line)
df = spark.read.json("path/*.json")

# Parquet (best for production)
df = spark.read.parquet("s3://bucket/data/")

# Generic with options
df = spark.read \
    .format("csv") \
    .option("header", "true") \
    .option("nullValue", "NA") \
    .load("path.csv")

# From Pandas
df = spark.createDataFrame(pandas_df)

Lazy Evaluation — The Core Concept

read()
→
filter()
→
groupBy()
→
withColumn()
→
join()
→ triggers →
show() / count() / write

🔵 Transformations — LAZY (build the plan)

select()filter()groupBy() join()withColumn()drop() orderBy()distinct()limit() union()repartition()

🟢 Actions — EAGER (run the plan)

show()count()collect() first()take(n)toPandas() write.*()printSchema()
Key insight: Spark builds a DAG (Directed Acyclic Graph) of all transformations. Nothing runs until an action is called — then Spark optimizes and executes the whole plan at once.

Select & Filter

# Select columns
df.select("name", "price")
df.select(df.name, df.price)
df.select(F.col("name"), F.col("price"))

# Filter / Where (identical)
df.filter(df.price > 10)
df.where("price > 10")          # SQL string
df.filter((df.price > 10) & (df.size == "L"))
df.filter(F.col("category").isin("Veggie", "BBQ"))
df.filter(F.col("name").isNotNull())

# Exclude / rename
df.drop("col_to_remove")
df.withColumnRenamed("old", "new")

Add & Transform Columns

# Add / overwrite a column
df.withColumn("tax", F.col("price") * 0.1)
df.withColumn("upper_name", F.upper("name"))
df.withColumn("rounded", F.round("price", 2))

# Conditional: when / otherwise
df.withColumn("tier",
    F.when(F.col("price") > 20, "premium")
     .when(F.col("price") > 10, "standard")
     .otherwise("budget"))

# Cast type
df.withColumn("qty", F.col("qty").cast("int"))

# String ops
F.concat(F.col("a"), F.lit(" - "), F.col("b"))
F.split(F.col("date"), "-")[0]    # first part

GroupBy & Aggregate

# Basic groupBy
df.groupBy("category").count()

# Multiple aggregations
df.groupBy("category", "size").agg(
    F.sum("total_price").alias("revenue"),
    F.avg("unit_price").alias("avg_price"),
    F.count("*").alias("orders"),
    F.max("quantity").alias("max_qty"),
)

# Sort results
.orderBy(F.desc("revenue"))

# Window functions
from pyspark.sql import Window
w = Window.partitionBy("category").orderBy("price")
df.withColumn("rank", F.rank().over(w))
df.withColumn("running_sum", F.sum("qty").over(w))

Joins

# Inner join (default)
df1.join(df2, "customer_id")
df1.join(df2, "customer_id", "inner")

# Left / right / full outer
df1.join(df2, "id", "left")
df1.join(df2, "id", "right")
df1.join(df2, "id", "outer")

# Multi-column join
df1.join(df2, ["order_id", "item_id"])

# Join with rename to avoid ambiguity
df1.join(df2, df1.id == df2.ref_id).drop(df2.ref_id)

# Semi (exists) / Anti (not exists)
df1.join(df2, "id", "left_semi")
df1.join(df2, "id", "left_anti")

# Parquet (best: compressed, columnar)
df.write.parquet("output/path")

# CSV with header
df.write.csv("output/", header=True)

# Write modes

    mode="overwrite",
    properties={"user": "u", "password": "p"}

Spark SQL

# Register as a SQL view
df.createOrReplaceTempView("orders")

# Run SQL against it
result = spark.sql("""
  SELECT category,
         SUM(total_price) AS revenue,
         COUNT(*) AS orders
  FROM orders
  WHERE size = 'L'
  GROUP BY category
  ORDER BY revenue DESC
""")

# Global view (across sessions)
df.createGlobalTempView("global_orders")
spark.sql("SELECT * FROM global_temp.global_orders")

# SQL ↔ DataFrame are interchangeable
# Both produce the same result and execution plan

UDFs — Custom Functions

from pyspark.sql.types import StringType

# Define Python function
def label_size(s):
    return {"S": "Small", "M": "Medium",
             "L": "Large", "XL": "XL"}.get(s, "Unknown")

# Register as UDF
label_udf = F.udf(label_size, StringType())

# Use it
df.withColumn("size_label", label_udf("pizza_size"))

# Decorator shorthand
@F.udf(StringType())
def my_udf(val): return val.upper() if val else None
⚠ UDF cost: UDFs break Spark's optimizer and serialize rows to Python one-by-one. Prefer built-in F.* functions; they run JVM-side and are 10–100× faster.

Partitions & Performance

# Check partition count
df.rdd.getNumPartitions()

# Increase partitions (after large join/agg)
df.repartition(200)           # random re-shuffle
df.repartition(10, "category") # by column

# Decrease partitions (before write)
df.coalesce(4)                  # no full shuffle

# Cache hot DataFrames
df.cache()    # = persist(MEMORY_AND_DISK)
df.unpersist()

# Tune shuffle partitions (default 200)
spark.conf.set("spark.sql.shuffle.partitions", "50")

# Broadcast small table to avoid shuffle join
df1.join(F.broadcast(df2), "id")

Key Concepts

SparkContext Entry point to cluster; manages executors. Accessed via spark.sparkContext
RDD Low-level distributed dataset. DataFrame is built on top — prefer DataFrame/SQL.
DAG Directed Acyclic Graph of operations. Spark optimizes and executes it on action.
Stage Group of tasks that can run without a shuffle. A shuffle boundary = new stage.
Shuffle Data redistribution across nodes. Triggered by groupBy, join, repartition. Expensive.
Partition Chunk of data processed by one task on one executor. More = more parallelism.
Executor JVM process on a worker node that runs tasks and stores cached data.
Driver Coordinates the job: builds the DAG, schedules tasks, collects results.

Structured Streaming

# Read from Kafka stream
df = spark.readStream \
    .format("kafka") \
    .option("kafka.bootstrap.servers", "localhost:9092") \
    .option("subscribe", "pizza_sales") \
    .load()

# Parse JSON payload
df.selectExpr("CAST(value AS STRING)")

# Write stream to console
query = df.writeStream \
    .format("console") \
    .outputMode("append") \
    .start()

query.awaitTermination()   # block until stopped
query.stop()               # stop the stream

Common Patterns

# Drop duplicates
df.dropDuplicates()
df.dropDuplicates(["order_id"])

# Fill / drop nulls
df.dropna()
df.dropna(subset=["price"])
df.fillna(0, subset=["qty"])
df.fillna({"price": 0, "name": "unknown"})

# Pivot table
df.groupBy("category") \
  .pivot("size", ["S", "M", "L", "XL"]) \
  .sum("total_price")

# Union two DataFrames (same schema)
df1.union(df2)
df1.unionByName(df2)   # match by col name

# Sample data
df.sample(fraction=0.1, seed=42)
df.limit(1000)          # first N rows
